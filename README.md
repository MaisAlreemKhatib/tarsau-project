# TARSAU PROJECT

## Sistem Programlama Projesi
Bu proje, Linux ortamında C dili kullanılarak geliştirilmiş basit bir arşivleme programıdır.

Programın adı: `tarsau`

Program sıkıştırma yapmadan metin dosyalarını tek bir `.sau` arşiv dosyasında birleştirir ve daha sonra tekrar açabilir.

---

# Özellikler

- Metin dosyalarını arşivleme
- `.sau` uzantılı arşiv oluşturma
- Arşiv dosyasını geri açma
- Varsayılan arşiv adı desteği (`a.sau`)
- ASCII format kontrolü
- Dosya izinlerini koruma
- Hata kontrolü
- Makefile desteği

---

make
